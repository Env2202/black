Install

Three ways to run the reformatter against the live Astrix site.

1. Chrome / Edge extension

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Load unpacked → select astrix-desktop/extension
  4. Visit astrix.elynn.me/auth

2. Tampermonkey userscript

  1. Install Tampermonkey (or Violentmonkey)
  2. Add userscript/astrix-desktop.user.js
  3. Reload Astrix — desktop mode activates ≥900px

3. Local proxy

  1. cd astrix-desktop/proxy && node server.mjs
  2. Open http://127.0.0.1:3847/auth
  3. HTML is proxied with the desktop CSS/JS injected

What it changes

  • /auth — split brand + form instead of a centered phone card
  • /intro, /onboarding, /paywall… — wider readable column (~720–880px)
  • /home, /chat, /profile — expands max-width shells; floats the bottom nav as a compact pill

This does not scrape private data or replace Astrix — it only restyles and lightly rearranges their existing DOM for desktop viewports.
